# cpp
Programlamaya Giriş dersinde kullanmak üzere hazırladığım C++ örnekleri.

## Hangi klasörü kullanmalıyım?

| Klasör | Kimler için |
|---|---|
| `Windows` | Windows kullananlar |
| `Linux-macOS` | Linux ya da macOS kullananlar ve OnlineGDB gibi çevrimiçi derleyicilerle çalışanlar |

İki klasördeki örnekler aynıdır. Linux-macOS klasöründeki örneklerde Windows'a özgü komutlar çıkarılmış ya da açıklama satırına dönüştürülmüştür.

## Önerilen IDE'ler

| IDE | Sistem | Not |
|---|---|---|
| [Code::Blocks](https://www.codeblocks.org/downloads/binaries/) | Windows, Linux | Windows'ta adında `mingw` geçen kurulum dosyası indirilmelidir. Bu dosya derleyiciyi de kurar. |
| [Visual Studio Community](https://visualstudio.microsoft.com/vs/community/) | Windows | Kurulumda "C++ ile masaüstü geliştirme" seçilmelidir. Türkçe karakterlerin doğru görünmesi için proje özelliklerinde C/C++ > Komut Satırı > Ek Seçenekler alanına `/utf-8` yazılmalıdır. |
| [Dev-C++](https://github.com/Embarcadero/Dev-Cpp/releases) | Windows | Dev-C++'ın farklı sürümleri vardır; Embarcadero sürümü önerilir. Adında TDM-GCC ve Setup geçen kurulum dosyası indirilmelidir. Bu dosya derleyiciyi de kurar. |
| [VS Code](https://code.visualstudio.com/) | Windows, Linux, macOS | C/C++ eklentisi ve derleyici ayrıca kurulmalıdır. |
| [CLion](https://www.jetbrains.com/clion/) | Windows, Linux, macOS | Ticari olmayan kullanım için ücretsizdir. Öğrenciler [JetBrains Öğrenci Paketi](https://www.jetbrains.com/student/) ile diğer JetBrains araçlarını da ücretsiz kullanabilir. |
